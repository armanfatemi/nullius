# Code of conduct

## The standard

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. That document is the authority; this file is the local
contact information and one note about what it means here.

## In short

Be decent. Assume good faith. Criticise work, not people.

## The note

This repository argues with itself in writing, on purpose. Its rules, specs and
retrospectives are blunt about failures — a design that reports success without
having checked anything is called exactly that, and the reasoning is written
down so it can be attacked.

**That bluntness is aimed at artefacts, never at people.** "This verdict is
wrong and here is the case" is the intended register. "You are careless" is
not, and being right about the code does not license it. If you cannot tell
which one you are writing, you are writing the second.

Disagreement is welcome here and does not need softening to be acceptable. What
is not acceptable is harassment, personal attacks, or making someone unwelcome —
in issues, pull requests, commit messages, or anywhere else this project reaches.

## Reporting

Report a concern to **arman.fatemi@gmail.com**.

Reports are handled confidentially. This is a single-maintainer project, so the
maintainer is also the person you would report the maintainer to — if that is a
problem for your report, say so and something else will be arranged.
